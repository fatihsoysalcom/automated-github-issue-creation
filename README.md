# Automated GitHub Issue Creation

This Python script demonstrates how to use an LLM to automatically generate structured GitHub issues from unstructured text. It parses feedback or bug reports and creates corresponding issues in a specified GitHub repository.

## Language

`python`

## How to Run

1. Set OPENAI_API_KEY and GITHUB_TOKEN environment variables.
2. Set GITHUB_REPO_NAME to your target repository (e.g., 'my-org/my-project').
3. Run the script: python generate_issues.py
